# Дыхание — Telegram Mini App

MVP-приложение с практиками дыхания для Telegram. Пользователь выбирает технику,
читает описание и проходит сессию с анимированным дыхательным кругом,
таймером фаз и счётчиком циклов.

## Стек

- React 19 + TypeScript
- Vite (сборка и dev-сервер)
- Без бэкенда и без базы данных — все техники дыхания захардкожены в
  `src/data/techniques.ts`
- Telegram WebApp JS Bridge (`telegram-web-app.js`) для интеграции с клиентом Telegram

## Структура проекта

```
src/
  types/            доменные типы + типы Telegram WebApp
  data/              каталог техник дыхания (данные, легко расширяется)
  hooks/
    useBreathingCycle.ts   состояние таймера дыхательной сессии
    useTelegramWebApp.ts   вся работа с Telegram WebApp bridge
  components/
    BreathingCircle/  анимированный круг — визуальное ядро приложения
    TechniqueList/     экран списка техник
    TechniqueDetail/   экран описания техники
    SessionScreen/      экран активной сессии
    ...                мелкие переиспользуемые UI-компоненты
  utils/               чистые вспомогательные функции
  styles/global.css     дизайн-токены (цвета, шрифты, отступы)
```

## 1. Что нужно установить

1. **Node.js версии 20 LTS или новее** (в комплекте с ним идёт npm).
   Скачать: https://nodejs.org/
   Проверить установку:
   ```bash
   node -v
   npm -v
   ```
2. **Git** (по желанию, для контроля версий и деплоя): https://git-scm.com/
3. Любой код-редактор, например **VS Code**: https://code.visualstudio.com/
4. Аккаунт в Telegram и доступ к **@BotFather** — понадобится для регистрации Mini App.

Устанавливать глобально ничего больше не нужно — Vite, TypeScript и линтер
уже прописаны в `devDependencies` и подтянутся через `npm install`.

---

## 2. Запуск в режиме разработки

```bash
cd breathing-app
npm install
npm run dev
```

Vite поднимет локальный сервер (обычно `http://localhost:5173`).
Откройте эту ссылку в обычном браузере — приложение полностью работает и
без Telegram (Telegram-специфичные функции просто не активируются: кнопка
«назад» и haptic feedback работают только внутри Telegram-клиента).

Полезные команды:

```bash
npm run dev       # dev-сервер с горячей перезагрузкой
npm run build     # проверка типов (tsc) + продакшн-сборка в папку dist/
npm run preview   # локальный просмотр уже собранной продакшн-версии
npm run lint      # статический анализ кода (oxlint)
```

## 3. Как проверить приложение внутри самого Telegram

Telegram Mini App обязательно должен открываться по **HTTPS**-адресу — localhost
для этого не подходит, поэтому нужен туннель или полноценный деплой.

### Вариант А. Быстрая проверка через туннель (ngrok)

1. Установите ngrok: https://ngrok.com/download
2. Запустите приложение: `npm run dev`
3. В отдельном терминале: `ngrok http 5173`
4. Скопируйте выданный `https://...ngrok-free.app` адрес — это и есть ваш
   временный HTTPS URL для Telegram.

### Вариант Б. Полноценный деплой (рекомендуется)

Соберите статику и разместите её на любом хостинге статических сайтов:

```bash
npm run build
```

Готовые файлы появятся в папке `dist/`. Их можно задеплоить, например, на:

- **Vercel** — `npx vercel deploy dist` (или подключить репозиторий в веб-интерфейсе)
- **Netlify** — перетащить папку `dist` в Netlify Drop (https://app.netlify.com/drop)
- **GitHub Pages** — запушить `dist` в ветку `gh-pages`

Все эти сервисы выдают готовый HTTPS-адрес — его и указываем в BotFather.

### Регистрация Mini App в BotFather

1. Откройте чат с **@BotFather** в Telegram.
2. Если бота ещё нет — создайте его: `/newbot`, следуйте инструкциям.
3. Настройте Mini App: `/newapp`, выберите вашего бота.
4. Укажите название, описание, картинку (по желанию) и **HTTPS-адрес**
   вашего приложения (из шага А или Б выше).
5. BotFather выдаст ссылку вида `https://t.me/<bot_username>/<app_name>` —
   откройте её в Telegram, чтобы запустить приложение.

Также можно привязать Mini App к кнопке меню бота командой `/setmenubutton`
в BotFather — тогда приложение будет открываться прямо из чата с ботом.

## 4. Как добавить новую технику дыхания

Логика и UI ничего не знают о конкретных техниках — они просто рендерят
данные. Чтобы добавить новую практику, достаточно добавить один объект в
массив `BREATHING_TECHNIQUES` в файле `src/data/techniques.ts`:

```ts
{
  id: 'my-technique',
  title: 'Название на русском',
  shortDescription: 'Короткое описание для карточки в списке',
  fullDescription: 'Полное описание для экрана деталей',
  benefits: ['Польза 1', 'Польза 2'],
  level: 'beginner', // beginner | intermediate | advanced
  recommendedCycles: 6,
  accentColor: '#7DD8C8',
  phases: [
    { kind: 'inhale', durationSec: 4, label: 'Вдох', hint: 'Подсказка для пользователя' },
    { kind: 'exhale', durationSec: 6, label: 'Выдох', hint: 'Подсказка для пользователя' },
  ],
}
```

Ничего в компонентах или хуках менять не нужно — экраны списка, деталей и
сессии автоматически подхватят новую технику.

## 5. Известные ограничения MVP

- Нет тестов и нет базы данных — по требованиям к текущей версии.
- Прогресс пользователя нигде не сохраняется (нет `localStorage`/бэкенда) —
  при перезапуске сессия начинается заново.
- Звуковое сопровождение фаз дыхания не реализовано, только визуальная
  анимация и haptic feedback внутри Telegram.
